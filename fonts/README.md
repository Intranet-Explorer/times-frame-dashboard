# Fonts

Third-party pixel/retro fonts used by the journal layout. Each is redistributed under its own license — see upstream for details.

| File | Font | Use | Source |
|---|---|---|---|
| `PixelifySans-latin-400.woff2` | Pixelify Sans | headlines / body | [Google Fonts](https://fonts.google.com/specimen/Pixelify+Sans) (OFL) |
| `VT323-latin-400.woff2` | VT323 | numerals / clock | [Google Fonts](https://fonts.google.com/specimen/VT323) (OFL) |
| `DotGothic16-latin-400.woff2` | DotGothic16 | labels | [Google Fonts](https://fonts.google.com/specimen/DotGothic16) (OFL) |
| `Toriko.ttf` | Toriko | title | Crusenho (check upstream license before redistribution) |

If you fork this publicly, verify each font's license permits redistribution, or swap in your own.
